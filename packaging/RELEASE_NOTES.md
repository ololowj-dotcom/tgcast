## Windows program, no Python needed

Download `tgcast-windows.zip`, unpack it, put `tgcast.exe` into an empty folder and double-click it. A menu guides you:
first-time setup, check chats, preview, send. See `README.txt` inside the archive.

The program is not digitally signed, so Windows SmartScreen may warn: click "More info" -> "Run anyway". The file is
built from this repository by GitHub Actions; compare its checksum with `SHA256SUMS.txt`
(`certutil -hashfile tgcast-windows.zip SHA256`).

## Windows-программа, Python не нужен

Скачайте `tgcast-windows.zip`, распакуйте, положите `tgcast.exe` в пустую папку и дважды щёлкните по нему. Меню
проведёт по шагам: первая настройка, проверка чатов, предпросмотр, отправка. Подробности в `README.txt` внутри архива.

Программа не имеет цифровой подписи, поэтому SmartScreen может предупредить: нажмите «Подробнее» -> «Выполнить в любом
случае». Файл собирается из этого репозитория в GitHub Actions; сверьте контрольную сумму с `SHA256SUMS.txt`
(`certutil -hashfile tgcast-windows.zip SHA256`).

Guide / Инструкция: https://github.com/ololowj-dotcom/tgcast
